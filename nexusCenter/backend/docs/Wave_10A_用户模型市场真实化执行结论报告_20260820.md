# Wave 10A 用户模型市场真实化执行结论报告

## 执行结论

Wave 10A 已完成开发、正式部署与全量回归。正式容器 `nexus-api-app-v16-wave10a` 当前为 `healthy`，Flyway 数据库版本保持 V16。本轮没有新增数据库迁移，也没有执行真实上游模型调用。

## 已完成功能

- 新增 `GET /api/v1/model-market`，支持服务分组、搜索、厂商、能力类型、流式能力、价格排序和分页。
- 市场只展示公开、启用且真实可路由的模型，路由必须具备有效分组、供应商、渠道、分组专用凭证和非熔断状态。
- 最终售价统一按每 1M Token，计算规则为模型基础售价乘服务分组倍率。
- API 令牌创建和编辑强制校验模型白名单属于绑定服务分组且当前可路由。
- 用户端模型市场改为真实接口数据，展示上下文窗口、最大输出 Token、能力标签和最终输入/输出价格。
- 从模型市场创建 API 令牌时自动预选服务分组和模型；API 令牌页使用真实模型复选列表，不再接收逗号文本白名单。

## 安全边界

- 模型市场响应不包含上游 APIKey、上游地址、渠道 ID、供应商成本或其他路由内部信息。
- API 令牌 Secret 仍只在创建成功时展示一次。
- 模型白名单权限由后端强校验，不能通过绕过前端选择器调用分组外模型。
- 用户数据继续按登录 Session 用户隔离。

## 已知限制与下一步

- 当前正式环境没有满足“公开、启用且真实可路由”条件的服务分组，因此 `/api/v1/model-market` 已上线但当前返回 0 个模型；本轮未擅自改变分组受众。
- 真实低用量请求仍可能受 8 位资金精度影响而舍入为零，发布后必须继续做非零扣费验收。
- 下一步：由管理员明确开放至少一个服务分组，再验证模型市场、创建 Key、真实调用、日志与非零计费闭环。
