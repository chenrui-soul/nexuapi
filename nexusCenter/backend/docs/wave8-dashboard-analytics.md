# Wave 8 经营数据聚合与管理员仪表盘

## 交付目标

```text
Gateway 完成请求并保存收入/成本快照
  → request_logs 保存最终请求事实
  → upstream_attempt_logs 保存每次真实上游尝试
  → 定时任务按小时和日幂等重算 usage_aggregates
  → 管理员查询总览、趋势、排名和错误归因
  → 前端 /admin/analytics 展示经营与稳定性指标
```

## 统计口径

- 最终请求成功：`status_code` 为 2xx 且没有平台错误码。
- 最终请求失败：除成功条件外的所有已完成请求，避免 SQL `NULL` 三值逻辑漏算失败。
- 供应商稳定性：按 `upstream_attempt_logs` 的每次真实尝试统计，重试成功不会覆盖前序供应商失败。
- 收入、供应商成本和毛利：只读取请求完成时写入 `request_logs` 的历史快照，不按当前模型价格反算。
- 总览、平均延迟和完整区间 P95：直接查询原始事实表。
- 趋势和供应商/模型/渠道/分组排名：读取小时或日级 `usage_aggregates`。
- 经营日界线：`Asia/Shanghai`；数据库和接口继续使用 `TIMESTAMPTZ`/ISO 时间。

金额通过 JSON 字符串传输并固定保留 8 位小数，前端不会把财务值转为 JavaScript 浮点数后重新计算。折线图坐标允许使用近似数值，但页面展示和接口原值保持精确十进制字符串。

P0 不提供汇率换算。统计区间内如果真正产生资金数据的请求包含多个供应商结算币种，接口返回 `VALIDATION_ERROR`，禁止静默相加并产生错误毛利。

## 聚合与并发

- 初次启动回填最近 90 天日桶和最近 48 小时时桶。
- 后续每 5 分钟重算最近 2 天日桶和最近 48 小时时桶，兼容晚到日志。
- PostgreSQL transaction advisory lock 保证多实例同一时刻只有一个聚合事务。
- 聚合使用唯一键 UPSERT 完整覆盖时间桶；同一区间重复执行不会重复计数。
- 聚合异常只降低统计新鲜度，不回滚 Gateway、计费或调用日志主链路。

## 管理接口

| 接口 | 权限 | 用途 |
|---|---|---|
| `GET /api/v1/admin/dashboard/overview` | Cookie Session + `ROLE_ADMIN` | 查询总览、趋势、排名、P95 和错误分布 |

查询支持 `today`、`7d`、`30d`、`90d`，或同时传入 `from`、`to` 的不超过 90 天自定义范围。返回字段只包含聚合指标和资源展示名称，不包含用户邮箱、API 令牌、上游 APIKey、渠道凭证、Authorization、请求/响应正文或异常原文。

## 管理页面

前端 `/admin/analytics` 包含：

- 今日、7/30/90 天和自定义日期范围。
- 最终请求、收入、成本、毛利、最终成功率和上游尝试稳定性。
- 收入/成本/毛利 SVG 趋势。
- 请求与上游延迟、缓存 Token、脱敏错误分布。
- 供应商、模型、渠道和分组前 10 排名。
- 首次聚合、聚合延迟、加载、错误和空数据状态。

## 配置项

| 环境变量 | 默认值 | 说明 |
|---|---:|---|
| `DASHBOARD_AGGREGATION_ENABLED` | `true` | 是否启用经营数据聚合 |
| `DASHBOARD_REFRESH_INTERVAL` | `5m` | 聚合调度间隔 |
| `DASHBOARD_INITIAL_DELAY` | `30s` | 应用启动后的首次聚合延迟 |
| `DASHBOARD_BACKFILL_DAYS` | `90` | 首次日桶回填天数，硬上限 90 |
| `DASHBOARD_RECENT_DAYS` | `2` | 周期性日桶重算天数，硬上限 7 |
| `DASHBOARD_RECENT_HOURS` | `48` | 周期性小时桶重算小时数，硬上限 168 |

## 当前限制

- P0 只支持统一核算币种，不支持汇率、税费和供应商账单对账文件。
- 完整区间 P95需要对最多 90 天事实数据排序；数据量显著增长后再评估 ClickHouse 或预计算近似分位数。
- 趋势只返回有事实数据的时间桶，前端会连接相邻数据点，不主动生成零值桶。

## 验证结果

- Wave 8 定向后端集成测试覆盖幂等、金额精度、P95、权限、时间范围、敏感信息和混合币种负例。
- Flyway V1-V9 支持 PostgreSQL 16 空库顺序迁移，V9 新增字段均有中文 COMMENT。
- 前端 ESLint、生产构建和自动化测试覆盖经营接口参数与敏感字段边界。
